# 路线②：报告只在手机的微信 / 支付宝小程序里

国内医院的报告查询大量长在微信和支付宝小程序里。这条路线讲怎么把它们弄到电脑上。

---

## 0. 先纠正一个方向性的错误

**不要试图驱动小程序。** 不要去做小程序自动化、不要装模拟器、不要抓小程序包。

原因是这样的：**医院小程序本质上是个魔改的浏览器，报告本身就是一张网页。**
小程序真正解决的是**认证**（微信/支付宝已经知道你是谁，省掉了登录），
而不是渲染——渲染的还是普通 H5。

**证据**：这类系统出的报告 PDF，页脚常常印着一条「溯源链接」，形如

```
https://wechat.zy91.com/wechatswin/outpatient/reportOfZJTestResult.htm?reportId=1024xxxxx
```

一个普通 https 页面 + 一个 `reportId`。既然如此，**正确的做法是把链接搬到电脑上的
Chrome 里打开**，然后并入 [路线①](10-acquire-browser.md) 用浏览器批量处理。

---

## 1. 首选：直接用**电脑版微信**打开小程序 / 公众号

这是最省事的一条，**先试它**，多数情况一步到位。

电脑版微信（Windows / macOS 都有）能直接运行小程序、也能打开公众号菜单里的页面。
既然报告本来就是 H5，那在电脑上打开它，链接就已经在电脑这一侧了。

**让用户这样做：**

1. 电脑上登录**微信 PC 版**（手机扫码确认，这一步只能他自己做）。
2. 在 PC 微信里找到医院的**小程序**或**公众号**：
   - 小程序：左侧边栏的「小程序面板」，或直接搜医院名字；
   - 公众号：搜医院名 → 进入 → 底部菜单里找「报告查询 / 检验结果 / 就医服务」。
3. 进到能看见报告列表的那一页。
4. 在报告页面上**点右上角「···」→「复制链接」**，或者有的版本直接有
   **「在浏览器中打开」**——有这个就直接点，最省事。
5. 把链接粘到电脑 Chrome 里打开。

**可能还要过一次轻认证**：有的医院在浏览器里会再要一次手机号 + 短信验证码，
或者让你选就诊人。**这一步让用户自己完成**（你不能代收验证码）。
过完之后这个 Chrome 会话就有登录态了。

**打开之后 → 直接转 [路线①](10-acquire-browser.md)**，用浏览器扩展批量抓取，
包括那段可以整段粘贴的提取提示词。

> 支付宝同理：支付宝也有电脑版，但小程序支持不如微信全。
> 支付宝渠道优先试下面第 2 节的"手机复制链接 → 传到电脑"。

---

## 2. 备选：手机复制链接 → 传到电脑

PC 微信这条走不通时（医院只做了手机端、或 PC 版打不开那个小程序），
退到"在手机上复制链接、传到电脑"。**先试一条**，结果决定后面怎么走。

### 第 1 步：让用户取出一条报告链接

在小程序里打开任意一份报告，然后：

- **微信**：右上角「···」→「复制链接」；没有这一项就试「分享给朋友」→ 发给
  **「文件传输助手」**，在电脑微信里点开
- **支付宝**：右上角「···」→「复制链接」或「分享」→ 发到电脑
- **都没有分享入口**：跳到第 4 步

### 第 2 步：在电脑 Chrome 里打开这条链接

让用户把链接发给你，你用浏览器打开。三种结果：

| 结果 | 说明 | 怎么走 |
|---|---|---|
| **直接看到报告内容** | 链接自带 token，或该站不校验登录态 | ✅ 走第 3 步 |
| **要求登录 / 跳到登录页** | 认证绑在小程序会话上，链接搬不动 | 先试第 3 步的变体，不行就第 4 步 |
| **页面报错 / 链接失效** | token 有时效，或做了 referer 校验 | 让用户重新复制一条最新的再试一次；仍不行 → 第 4 步 |

**要求登录时还有一招值得试**：让用户在电脑 Chrome 里**用同一个平台的网页版登录**
（很多医院既有小程序也有官网，账号是通的），登录后再打开那条链接。
成功的话就完全变成路线①了。

### 第 3 步：能打开 → 转路线①

链接能开就说明这套系统在电脑上是通的。让用户把**所有**报告的链接导出来
（或者干脆在电脑上找到列表页），然后按 [`10-acquire-browser.md`](10-acquire-browser.md)
批量下载。

导链接的笨办法但有效：在小程序里逐份「复制链接」→ 发到文件传输助手 →
电脑上一次性复制出来。二十份以内这样最快。

### 第 4 步：打不开 → 降级到手机截图

这是完全可以接受的结果，别硬撑。跟用户说清楚：

> 这家医院的报告链接离开手机就打不开了，我们改用截图。
> 请在小程序里打开每份报告，**滚动截长图**（iPhone 用「整页」，
> 安卓多数有「长截图」），然后把图发到电脑。

然后走 [`12-acquire-manual.md`](12-acquire-manual.md)，由你读图。
长截图能完整包含一份报告，效果其实相当好。

## 3. 各渠道的搬运通道速查

| 从哪到哪 | 怎么走 |
|---|---|
| 微信 → 电脑 | 「文件传输助手」，或「收藏」后在电脑微信里打开 |
| 支付宝 → 电脑 | 分享到微信/钉钉，或存相册后用其它方式传 |
| iPhone → Mac | 隔空投送（AirDrop），最省事 |
| 安卓 → 电脑 | 数据线、或各家自带的传输助手 |
| 通用兜底 | 发一封邮件给自己（附件带图） |

**微信里能直接存 PDF 的情况**：有些医院的小程序提供「下载报告」，
会生成一个 PDF 存到微信文件里。这种最理想——让用户在电脑微信里
「另存为」，直接就是路线③的 PDF 输入。

---

## 4. 红线重申

- **不要代用户操作他的微信/支付宝账号**，不要索要账号密码，不要代收验证码。
  你的角色是**告诉他怎么做**，操作由他自己完成。
- 用户发过来的链接**只用来取他自己的报告**。这类链接的 `reportId` 常常是连续数字，
  **绝对不要去枚举**——那是在访问别人的病历。
- 链接和截图里可能带姓名、就诊卡号等信息，处理完照常放 `workspace/`（已 gitignore），
  不要外发。
