# 路线③：已有 PDF / 照片 / 录屏

**这是兜底路线，也是覆盖面最广的一条。** 拿不准走哪条时，先走这条。
另外两条路线（浏览器批量下载、手机小程序）最终也都汇到这里——
它们只是帮用户**把文件弄到电脑上**，弄到之后的处理是一样的。

目标只有一个：把文件放进 `workspace/inbox/`，然后 `python3 tools/probe.py workspace/inbox`。

---

## 1. PDF —— 最省事，优先推荐

直接拖进 `workspace/inbox/` 就行。**告诉用户不用改名、不用整理、不用分类**——
文件名乱七八糟没关系，日期以 PDF 正文里印的为准（文件名里的日期经常是错的，见坑 §4.6）。

医院/体检机构给的 PDF 通常有文字层，`tools/extract.py text` 能直接读出精确字符，
这是最理想的情况。

**如果是压缩包**：

```bash
python3 -c "import sys;sys.path.insert(0,'tools');from lib import unzip_cjk;unzip_cjk('workspace/inbox/xxx.zip','workspace/raw')"
```

用 `unzip_cjk` 而不是普通 `unzip`：Windows 打的包在 macOS/Linux 上解出来中文文件名会变乱码
（坑 §4.1），这个函数会按 cp437→utf-8/gbk/big5 试探修回来。

**如果 PDF 有密码**：`probe.py` 会标出来。**让用户自己解密**——
不要去猜密码、不要去暴力破解，那既没必要也不合适。常见密码是身份证后 6 位之类，
用户自己知道，让他用 Preview / Acrobat 另存一份无密码的。

---

## 2. 照片 / 截图

用户手机里常见的三种：

| 形态 | 怎么处理 |
|---|---|
| 拍的纸质化验单 | 直接放进来。提醒用户**拍正、拍全、别糊**——拍不清你就读不准 |
| 小程序/App 里的长截图 | 直接放进来，一张长图能包含整份报告 |
| 一份报告拍了好几张 | 也直接放，按顺序命名（`01-1.jpg` `01-2.jpg`）方便你归位 |

这些都走**第 2 层**：

```bash
python3 tools/extract.py pages workspace/inbox/化验单.jpg
```

然后**你自己用 `Read` 打开那张图读数值**。你是多模态模型，读中文化验单比任何 OCR 引擎都准，
而且不用装任何东西。

**读的时候三条规矩：**

1. **异常值复读一次**再定稿。偏高偏低的那几项是用户最在意的，读错代价最大。
2. **读不清就标「待核对」**，写进 `footNotes` 告诉用户，**不要猜一个像样的数字填进去**。
3. **参考区间照抄原文**（`12.3-107.0` / `≥50` / `阴性`），不要归一化、不要换算。

如果图片实在糊到读不出来，让用户**重拍**，这比你猜强得多。

---

## 3. 录屏（最次要，但有时是唯一办法）

有些 App 不让截图、不让导出，用户只能录屏翻页。ffmpeg 抽帧去重：

```bash
ffmpeg -i 录屏.mp4 -vf "fps=2,mpdecimate" -vsync vfr workspace/raw/frame_%04d.png
```

- `fps=2` 每秒抽 2 帧，翻页速度慢的话 `fps=1` 就够
- `mpdecimate` 丢掉和前一帧几乎相同的画面——这是关键，否则几分钟录屏能出上千张几乎一样的图
- 抽完先 `ls | wc -l` 看看数量，太多就调低 fps 重来

抽出来的帧同上，走第 2 层由你读。翻页动画会产生一些糊帧，直接跳过即可。

---

## 4. Excel / 汇总表

体检机构常给一个汇总 Excel。`probe.py` 会列出 sheet 名和行列数。

**汇总表很有用但不可全信**——它是别的程序导出的，已知会出这些问题：

- 把不同时期的参考区间压成一个（坑 §4.3）
- 漏标定性异常，只认 ↑↓ 不认「隐血 +++」「清洁度 Ⅲ」（坑 §4.9）
- 长表 vs 宽表两种结构都有，长表要自己 pivot（坑 §4.7）

**如果同时有汇总表和逐份 PDF，两边都抽，然后对撞**——这是最强的核对方式，
比任何单一来源都可信。对不上的地方列给用户，写进 `footNotes`。

---

## 5. 收完之后

```bash
python3 tools/probe.py workspace/inbox
```

把勘探结果讲给用户听：多少份、覆盖哪段时间、哪些能直接读、哪些要你看图。
如果发现明显缺口（比如只有 2026 年的、没有更早的），**问一句**——
用户往往还有一批忘在别处，趋势图有两个点和有五个点差别很大。
