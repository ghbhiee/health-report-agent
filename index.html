把散落各处的体检报告，
变成一个双击就能打开的健康看板

化验能看多年趋势，报告原件内嵌可查，影像图能翻。一个 HTML 文件，全程本地，不上传任何数据。 Turn scattered medical reports into one self-contained HTML health dashboard. Runs entirely on your machine — nothing is uploaded.

▶ 打开可交互的演示看板 GitHub 仓库 使用说明

它怎么工作

  • 把这个项目目录交给 Claude Code / Codex 之类的 agent
  • 它引导你把报告弄到手——已有 PDF 直接放进去，或用电脑版微信打开医院小程序、把报告页转到 Chrome 用扩展批量抓
  • 读懂内容（有文字层的 PDF 直接取，扫描件和照片由 agent 自己看图），生成页面
关于演示数据　演示看板与视频里的姓名、日期、化验数值、报告结论和全部图片， 都是程序合成的虚构内容，不对应任何真实个人、医疗机构或医学影像。
不做医学诊断　这个工具只是把你已有的报告重新组织展示，任何解读请以医生意见为准。
